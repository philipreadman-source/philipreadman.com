# philipreadman.com

Portfolio site for Philip Readman. Static HTML, CSS and JS in `site/`, published to GitHub Pages on every push to `main`.

- Preview locally: `node serve.mjs` → http://localhost:4321
- Images: `node tools/optimise-images.mjs <2x export> site/img/<case>/<name> [--photo]`

Designs live in Figma ("Philip Readman Portfolio"), which is the source of truth.
